04 · The fintech edge

In a fintech, a leak can be a crime

An assistant that can read everything can also leak everything. For a payments company supervised by MAS, that blocks rollout entirely.

01
Tipping-off
Telling a customer that a suspicious-transaction report exists is an offence (CDSA s.57; MAS Notice PSN01).
02
Card data
Card numbers pasted into a ticket must never reach an index or a model (PCI DSS 3.4.1).
03
Oversharing and injection
Assistants oversharing, and instructions hidden in retrieved documents (EchoLeak, Slack AI), are on record.
04
Stale permissions
Synced permissions lag the source by 30 minutes to a day. A removed person keeps seeing what they should not.
So the answer has to be useful and permission-safe at the same time.
The model must never see anything the person asking cannot see, and compliance must be able to prove it afterwards.
