Honest limits, and what's next

What we don't claim yet

  • The four platforms are mocked with their real API shapes and permission rules; the connectors haven't run against a real tenant yet.
  • Sign-in is a demo login standing in for SSO; a deployed build refuses to start without a passcode.
  • The grounding check verifies numbers and names, not the relations between them.
  • Someone holding the ledger's sealing key could rewrite records after the last off-host published head; we say so and test it.
  • All numbers come from a test model and the deterministic path; the Hy3 run waits on Tencent account verification.
