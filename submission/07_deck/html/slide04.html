How it works

Two checks before the model. One after. A record before anything is shown.

01
Who's asking
A signed token from the web app or WorkBuddy. Never a name typed into a box.
02
Gate 1
Search only what this person may open, using each platform's own permission model.
03
Gate 2
Ask the source again, live, for every passage. Error or timeout means no.
04
Answer
Tencent Hy3 via TokenHub writes from those passages only, or we quote them directly.
05
Grounding
Every sentence cites a passage; unsupported numbers and names are dropped.
Audit log: written before retrieval, before the model, before the answer is shown. Hash-chained and sealed. If it can't be written, nothing is answered.
Restricted = doesn't exist
The same refusal, byte for byte, whether a document is restricted or was never written.
Revoked = gone next question
Remove someone from a channel and their very next answer no longer uses it, even if the notification is lost.
Changed = re-read first
An edited document is re-read and re-checked before use, and the citation shows the new version.
