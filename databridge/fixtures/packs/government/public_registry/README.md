# public_registry -- JSON API snapshots (T2)

> SYNTHETIC FIXTURE. Generated by `../generate.py`. Every business,
> licence and officer name is invented.

Captured responses from the (fictional) Aldermoor Territory public
registry: business registrations and premises licences, paginated exactly
as the API returns them -- `meta` block with `etag`, `next_cursor`, page
counts and a retention notice, then `data`.

```
snapshots/2026-05-01/businesses_page_001.json
snapshots/2026-05-01/licences_page_001.json
snapshots/2026-08-01/...
snapshots/manifest.json
```

## Why two snapshots

A current-addressable source cannot answer `as_of`. The only honest way to
test verification against it is to hold two captures and compare. See
`DRIFT.md` for exactly what moved between them and what verdict each
change should produce.

## Entity resolution

Business officers are recorded `Surname, Forenames`, a different shape from
both PERMITWORKS and CLAIMLINE, and many of them are people who also appear
in those systems. Some entries carry only an initial. There is no
identifier of any kind on an officer record -- name and address are all
there is, which is precisely the situation that makes automatic merging
unsafe.
