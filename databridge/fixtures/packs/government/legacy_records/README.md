# legacy_records -- LEGACY-MASTER extract

> SYNTHETIC FIXTURE. Generated by `../generate.py`. Nothing here is real.

`data/LEGACY_MASTER_part*.dat` -- 8,000 fixed-width records of 220 bytes each.
Read `LAYOUT.md` for the field table and `COPYBOOK.cpy` for the COBOL
declaration. Both are generated from the same table in `../generate.py`.

Parsing, in one line:

```python
widths = [w for _n, _p, w in LEGACY_FIELDS]   # see ../generate.py
```

## What makes this the hard source

* **No history.** Full re-cut nightly, no cursor, no tombstones. T3.
* **Surnames truncated at 30 characters.** Hyphenated names lose their tail,
  which is exactly the population most likely to be double-registered.
* **Uppercase only**, so casing carries no signal for matching.
* **93 impossible dates** and **57 blank primary keys** survive from the 1998 system. They are preserved,
  not repaired -- a source that lies is part of the test.
* **Roughly 8% of records are orphans**: people who never appear in
  PERMITWORKS or CLAIMLINE at all. A resolver that forces every legacy row
  onto a known person is wrong.
* Permit and benefit references here use retired schemes and do **not**
  match the modern `AM-P-YYYY-NNNNNN` / `Bnnnnnnn` formats.
